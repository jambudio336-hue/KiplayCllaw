# Full-Stack Engineering
Plan, implement, debug, and verify maintainable web, Android, and backend projects.

## Trigger
fullstack engineering

## Steps
1. Inspect the repository, build scripts, framework versions, README, and tests.
2. Translate the request into acceptance criteria and a small implementation plan.
3. Check architecture, data flow, error states, accessibility, responsive UI, and security boundaries.
4. Make focused changes; preserve existing conventions and avoid unnecessary dependencies.
5. Keep secrets out of source control; use environment configuration and least privilege.
6. Run relevant unit tests, lint, type checks, and builds; fix root causes rather than masking failures.
7. Verify outputs and state what was actually tested, what remains untested, and how to run the project.
8. For risky shell commands or destructive file changes, explain the effect and request approval.
